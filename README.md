# EventEase Application

## Overview
EventEase is a Blazor WebAssembly application that allows users to view events, register, and track attendance.

## Copilot Usage Summary
Microsoft Copilot assisted throughout the development process by generating component templates, suggesting Blazor syntax for two-way data binding, routing, and validation. Copilot helped debug routing issues, optimize form validation, and accelerate implementation of advanced features such as registration forms, session state management, and attendance tracking.

## Features
- Event Card component with two-way data binding
- Routing between pages
- Input validation
- User registration and session state
- Attendance tracking

## Technologies
- Blazor WebAssembly
- .NET 8
